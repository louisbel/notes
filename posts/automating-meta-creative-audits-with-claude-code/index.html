Automating Meta Creative Audits with Claude Code

Building a competitor Creative Tracker with Claude Code

February 4, 2026

In the world of Meta Ads marketing, especially when you’re managing multiple brands, keeping a pulse on the competition usually feels like a chore. You spend hours clicking through the Facebook Ad Library, taking screenshots, and trying to remember if that one creative is actually new or just a recycled asset from a previous month.

I used Claude Code to build a Python-based workflow that turns the chaos of the Ad Library into a structured, visual database. It is not just a scraper; it is a full analysis pipeline that handles everything from high-res image extraction to video “hook” analysis and word cloud generation.

The Problem: The “Ad Library” Short Term Memory

The Facebook Ad Library is a goldmine, but it is built for transparency, not for scale. If you want to compare your brand’s messaging against four different competitors, you are stuck with twenty browser tabs and a lot of manual scrolling.

The Solution: The “Slipstream” Workflow

I wanted a tool that could:

  • Track “New” vs. “Existing”: Identify exactly what has been launched since my last check.
  • Analyze Video Hooks: Automatically extract frames at 1-second intervals to see the “hook” (the first 3 seconds) without hitting play 50 times.
  • Visualize Messaging: Generate word clouds to see which keywords our competitors are bidding on most frequently.
  • Create Portable Reports: One single, self-contained HTML file with all images embedded.

How it Works

The workflow is broken down into three main scripts, triggered by a simple urls.txt configuration where you define your own brands and your competitors.

1. The Extraction (fetch_competitors.py)

Using Playwright, the script navigates the Ad Library, handles the infinite scroll, and captures creative assets at a 3x device scale factor. This ensures that even the fine print in the ad copy is crystal clear.

One of my favorite features is the Video Timeline. It does more than grab a thumbnail; it creates a horizontal strip of the video’s progression. Any frame within the first 3 seconds gets a _HOOK tag and a red border in the final report, making it immediately obvious how a competitor is trying to stop the thumb-scroll.

2. The Data Layer (ad_tracking_db.json)

Every ad is hashed based on its body text and CTA. The script maintains a local JSON database that tracks the “First Seen” and “Last Seen” dates. When I run the report, it shows exactly how many new ads were detected in the latest run.

3. The Visuals (generate_report_html.py)

The final output is a responsive HTML report. I designed it with a 75/25 split: the creative on the left and the copy on the right. Because all images are Base64-encoded, I can Slack or email the single .html file to a teammate. Everything—the word clouds, the collages, and the timelines—works perfectly without needing an “assets” folder.

Leveling Up with AI

The real “unlock” happens once the data is gathered. I’ve started feeding the generated collages into Claude to get a high-level creative audit.

Instead of me staring at 100 ads, I can ask:

“Looking at these three competitor collages, what are the primary emotional hooks they are using compared to our brand?”

The AI can see the patterns in seconds, such as a competitor shifting from “Product-focused” to “UGC-style” content.

Looking Ahead

This is currently running on a weekly cron job, giving me a fresh report every Monday morning. Future iterations might include automated alerts for new campaign launches or a platform breakdown (Instagram vs. Facebook).

For now, it is just nice to have the data work for me, rather than the other way around.
