I Raced Claude Code to Launch ChatGPT Ads

29 May 2026·653 words·4 mins

Does it get more meta than using Claude Code to build and launch ChatGPT Ads?

Joke aside, I have wanted to run a clean “man versus machine” test for a while, and the new ChatGPT Ads manager was the perfect excuse. The platform was brand new to me, and brand new to Claude’s memory.

So I raced it. Same brief, same Google Ads performance data, same creative library. I built the campaign by hand. Then I handed Claude Code a single CLAUDE.md and let it build the same thing through the OpenAI Ads API.

What took me 24 minutes to set up by hand, Claude did in 8, running Opus 4.8 on high.

The number that actually matters is the second row. I launched one ad unit. Claude launched fifty. Once an agent has a working pattern, producing fifty creative-and-copy variants costs the same as producing one.

None of this came from the model being clever on its own. The speed, and just as importantly the quality, came from two things: very thoughtful instructions, and connecting Claude to the right inputs.

The leverage was the brief, not the model
#

The whole thing ran off one CLAUDE.md: a single markdown file doing the job of an onboarding doc, a standard operating procedure, and a QA checklist at once.

It read what already converts from Google Ads, pulled voice and image rules from my creative guidelines, picked images from a local library, and pushed campaigns, ad groups, and ads straight to the OpenAI Ads API. It wired conversion tracking through Google Tag Manager. And it governed itself: everything uploaded paused by default, every change logged to a CHANGELOG.md with a one-line rationale, and the account state backed up before any mutation.

That last part is what makes it usable in production, not just an impressive demo. An agent that ships fifty ad units and cannot tell you what it changed is a liability. An agent that ships fifty ad units, pauses them all, and hands you a versioned changelog is a junior media buyer who documents better than most.

The one thing I actually had to learn
#

Speed aside, the platform forced a real mental shift.

ChatGPT Ads do not target keywords. They target context hints: plain-language descriptions of a conversational moment, matched on intent rather than on an exact string. OpenAI’s own documentation is explicit that these are not exact-match keywords and do not guarantee delivery.

So the work is not “find the high-volume keyword.” It is “describe the person and the moment in the words they would use talking to an assistant.” My top Google terms became conversational situations. That is a different muscle, and it happens to be one a well-briefed agent is genuinely good at, because reshaping structured keyword data into natural language is exactly the kind of task LLMs handle well.

What this actually changes
#

The easy takeaway is that AI compresses ad-management work, and it does. The more interesting one is about reach.

The cost of standing up a competent account on a brand-new ad platform just dropped to an 8-minute job. For years, the practical barrier to testing a new channel was not budget, it was the setup tax: learning the interface, the taxonomy, the tracking, the naming conventions. That tax is what kept most performance teams camped on two or three platforms.

The setup was never the moat. Knowing what good looks like is. The CLAUDE.md that beat me did not contain a secret: it contained judgment, encoded as rules. The open question is whether that stays a durable advantage, or whether it is just the next thing the model learns to do without being told.
